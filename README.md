# Python OOP Mini Projects Portfolio

## Overview

This repository contains two Object-Oriented Programming (OOP) mini-projects developed in Python as part of the OOP with Python coursework.

### Project 1: Weather Forecast Application

A weather forecasting system that integrates with the Open-Meteo APIs to retrieve and analyze weather data for a specified location.

Key features include:

- Location geocoding using the Open-Meteo Geocoding API
- Weather forecast retrieval using the Open-Meteo Forecast API
- JSON data processing
- Pandas DataFrame creation and analysis
- Summary weather statistics
- Error handling with retry mechanisms
- Object-Oriented Programming design

### Project 2: Uganda Tax Engine

A modular tax computation system that models selected Uganda tax obligations using Object-Oriented Programming principles.

Key features include:

- PAYE tax calculations
- NSSF contribution calculations
- Local Service Tax calculations
- Corporate Income Tax calculations
- Payroll processing and net pay computation
- Tax scenario comparison using a Tax Planner
- Decimal-based financial computations
- Abstract classes, inheritance, and custom exceptions
- Boundary-value testing
